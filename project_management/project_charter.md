# Enterprise AI Governance Remediation Program — Project Charter

| Charter Item | Detail |
|---|---|
| **Project Name** | Enterprise AI Governance Remediation Program |
| **Project Objective** | Reduce governance risk across NorthStar Manufacturing’s highest-priority AI systems by addressing critical control weaknesses, strengthening oversight, and improving monitoring. |
| **Scope** | Top 5 AI systems identified through the Governance Priority Score |
| **Timeline** | October 2026 – March 2027 |
| **Project Sponsor** | Chief Risk Officer |
| **Project Lead** | AI Governance Analyst |
| **Key Stakeholders** | System Owners, HR, IT, Cybersecurity, Legal, Privacy, Finance, Data/Analytics |
| **Key Deliverables** | Remediation plan, fairness testing, access-risk model validation, security/access improvements, transparency documentation, monitoring improvements, control testing |
| **Success Metrics** | Increase control coverage toward 90%; eliminate missing priority-system controls; assign accountable owners; complete follow-up assessments |
